# Vercel Speed Insights Integration

This document describes the Vercel Speed Insights integration for the OmniStream project.

## Overview

Vercel Speed Insights has been successfully integrated into this FastAPI application to monitor real-world performance metrics and ensure optimal user experience.

## What Was Installed

- **Package**: `@vercel/speed-insights` (v1.3.1)
- **Framework**: FastAPI (Python backend with HTML frontend)
- **Integration Method**: HTML5 script injection (as per Vercel's official documentation)

## Implementation Details

### 1. Package Installation

Created `package.json` and installed the Speed Insights package:

```bash
npm install @vercel/speed-insights
```

### 2. FastAPI Integration

The Speed Insights script has been integrated into the main HTML page served by FastAPI (`backend/app.py`).

According to [Vercel's Speed Insights Quickstart Guide](https://vercel.com/docs/speed-insights/quickstart), for HTML5 applications, the integration requires:

```html
<!-- Vercel Speed Insights -->
<script>
    window.si = window.si || function () { (window.siq = window.siq || []).push(arguments); };
</script>
<script defer src="/_vercel/speed-insights/script.js"></script>
```

This has been added to the `<head>` section of the HTML returned by the root endpoint.

### 3. Backend Structure

Created the complete backend module with:
- `backend/__init__.py` - Package initialization
- `backend/app.py` - Main FastAPI application with Speed Insights
- `backend/downloader.py` - Media download functionality
- `backend/extractors.py` - Platform detection utilities

### 4. Vercel Configuration

Created `vercel.json` to properly configure the deployment for Vercel's platform.

## How It Works

1. When users visit the application, the Speed Insights script is loaded
2. The script automatically collects real-world performance metrics including:
   - First Contentful Paint (FCP)
   - Largest Contentful Paint (LCP)
   - First Input Delay (FID)
   - Cumulative Layout Shift (CLS)
   - Time to First Byte (TTFB)
3. Metrics are sent to Vercel's Speed Insights service
4. Data is available in the Vercel dashboard under "Speed Insights"

## Verification

After deployment to Vercel:

1. Deploy the application: `vercel deploy`
2. Visit your deployed site
3. Open browser DevTools → Network tab
4. Verify the `/_vercel/speed-insights/script.js` loads successfully
5. Check the Vercel dashboard → Select your project → "Speed Insights"

## Testing

The application can be tested locally:

```bash
# Install dependencies
pip install -r requirements.txt
npm install

# Run the server
python run.py
```

Then visit `http://localhost:5000` to see the application with Speed Insights enabled.

## Technical Notes

- **Framework Compatibility**: Speed Insights is a JavaScript package designed for frontend frameworks. Since this is a Python FastAPI backend, we use the HTML5 integration method.
- **Script Loading**: The script is loaded with the `defer` attribute to avoid blocking page rendering.
- **Performance Impact**: Speed Insights is designed to have minimal performance impact (~1-2KB gzipped).
- **Data Privacy**: Speed Insights only collects performance metrics, not user data.
